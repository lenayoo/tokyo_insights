Tokyo Insight

Calm Tokyo observations, built for fast Shorts.

Daily Workflow

1. Generate

Run python3 scripts/generate_daily_topics.py to create or refresh today's files.

2. Review

Open the daily preview page, skim hooks, scripts, and B-roll, then choose the best 3 to 5 topics.

3. Produce

Record voiceover, collect clips, and move the selected topics into CapCut or your publishing workflow.

Archive

Each day produces a JSON topic file and a matching HTML preview.
